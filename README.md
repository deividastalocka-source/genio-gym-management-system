# Genio Gym Management System

An international internship project developed at **Quidgest in Lisbon, Portugal**, focused on designing and building a gym management system using the **Genio development platform**.

The system was designed to provide a structured way for gym staff and administrators to manage information relating to clients, employees, instructors, gym locations, exercises and workout plans.

> **International Internship Project — Quidgest, Lisbon, Portugal | 2022**

## Project Overview

The project involved designing a relational data model and implementing it within Genio to create a functional gym management system.

The system provides separate **Admin** and **Staff** accounts with different access levels. Administrators have greater privileges for managing the system, while staff access is restricted to the functionality required for their role.

Forms and a structured menu system were also implemented to make data entry and navigation accessible without requiring users to interact directly with the underlying database.

## Key Features

- Relational database structure for managing gym information
- Admin and Staff user roles with different access levels
- Client and membership management
- Employee and instructor management
- Gym location management
- Exercise and workout type management
- Client workout plan management
- Data-entry forms for interacting with system records
- Structured menu navigation
- Customised application interface

## System Components

The system contains interconnected data structures for:

- Clients
- Employees
- Instructors
- Gyms
- Exercises
- Workout Types
- Workout Plans

Relationships between these components allow information from different areas of the system to be combined when creating and managing client workout plans.
