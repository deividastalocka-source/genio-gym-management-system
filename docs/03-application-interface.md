# Application Interface

## Overview

The Gym Management System includes a graphical interface that allows users to access and manage information stored within the system.

The interface was configured in Genio and includes separate dashboards, management pages and navigation options for accessing different areas of the application.

## Login

Users access the Gym Management System through a login screen.

![Gym Management Login](../screenshots/01%20-%20Gym%20Management%20Login.png)

This provides the entry point into the application before accessing the available system features.

## Admin Dashboard

The Admin Dashboard provides access to the main management areas of the system.

![Admin Dashboard](../screenshots/02%20-%20Admin%20Dashboard.png)

Administrators can use the interface to navigate between different parts of the application and manage the information stored within the system.

## Staff Dashboard

A separate Staff Dashboard was also created for staff members.

![Staff Dashboard](../screenshots/03%20-%20Staff%20Dashboard.png)

This provides staff with an interface for accessing the areas of the system relevant to their work.

The system includes a user management interface for managing application users.

## Interface Configuration

The application layout was configured within Genio to organise how the system is presented to users.

![Application Layout Configuration](../screenshots/12%20-%20Application%20Layout%20Configuration.png)

The visual appearance of the application was also customised using the theme configuration tools.

![Theme Builder](../screenshots/13%20-%20Theme%20Builder.png)

Together, these settings helped create a consistent interface across the different areas of the Gym Management System.

## Summary

The completed interface provides users with a structured way to navigate the Gym Management System and access its main features. Separate dashboards, management pages and interface configuration were used to turn the underlying database into a usable application.
