# Conclusion

## Project Summary

The Gym Management System was developed during an internship at Quidgest in Lisbon using the Genio development platform.

The project involved working alongside another intern to design and develop a database-driven application for managing gym operations.

## What Was Built

The completed system brought together several areas of gym management within one application, including:

- Clients
- Employees
- Gyms
- Instructors
- Exercises
- Workout types
- Workout plans

A relational database was used to organise the information, with primary and foreign keys connecting related records.

Genio was then used to build the forms, management pages, dashboards and navigation required to interact with the underlying data.

## What I Learned

This project provided practical experience with relational database design and application development.

It strengthened my understanding of how tables and relationships can be used to structure information within a business application and how a database can be developed into an interface that users can interact with.

Working alongside another intern also provided experience collaborating on a technical project and contributing towards a shared outcome.

## Final Result

The final result was a working Gym Management System that demonstrated the complete development process from database design through to the application interface.

The project was presented to the team at the end of the internship, providing an opportunity to demonstrate the completed application and explain its functionality.

This project became one of my earliest practical experiences developing a complete technical solution and provided a foundation for the systems, networking and IT projects I developed later.
