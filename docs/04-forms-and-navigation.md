# Forms and Navigation

## Overview

The Gym Management System uses a menu structure and individual forms to allow users to navigate between different areas of the application and work with information stored in the database.

Forms were created in Genio for the main entities within the system, providing a structured interface for entering and managing records.

## Menu Structure

The application menu provides access to the main areas of the Gym Management System.

![Menu Tree](../screenshots/22%20-%20Menu%20Tree.png)

The menu includes access to clients, gyms, employees, instructors, workout plans, workout types and exercises.

## Forms

Genio was used to create forms connected to the underlying database tables.

![Forms List](../screenshots/23%20-%20Forms%20List.png)

Each form provides fields corresponding to the information required for that part of the system.

## Client Form

The Client form is used to manage client information, including their personal details and membership information.

![Client Form](../screenshots/24%20-%20Client%20Form.png)

## Employee Form

The Employee form is used to manage employee information and associate employees with a gym.

![Employee Form](../screenshots/25%20-%20Employee%20Form.png)

## Exercise Form

The Exercise form allows exercises to be entered into the system and associated with a workout type.

![Exercise Form](../screenshots/26%20-%20Exercise%20Form.png)

## Gym Form

The Gym form stores information about individual gym locations.

![Gym Form](../screenshots/27%20-%20Gym%20Form.png)

## Instructor Form

The Instructor form is used to manage information about instructors, including their personal details and specialty.

![Instructor Form](../screenshots/28%20-%20Instructor%20Form.png)

## Workout Type Form

The Workout Type form allows different workout categories to be created and managed.

![Workout Type Form](../screenshots/29%20-%20Workout%20Type%20Form.png)

## Workout Plan Form

The Workout Plan form brings together information from different areas of the system to create a workout plan for a client.

![Workout Plan Form](../screenshots/30%20-%20Workout%20Plan%20Form.png)

The form allows existing information such as the client, instructor, gym and workout type to be used when creating a workout plan.

## Summary

The menu structure and forms provide the connection between the application's interface and its underlying database. Users can navigate between the main areas of the system and use dedicated forms to work with the information stored in each table.
