# Skills Demonstrated

## Overview

The Gym Management System project provided practical experience in designing and developing a database-driven business application using Genio.

The project involved planning the database structure, creating relationships between data, developing forms and configuring the application interface.

## Database Design

The project demonstrates an understanding of relational database design and how information can be separated into structured tables.

This included working with:

- Tables and fields
- Primary keys
- Foreign keys
- Relationships between records
- Structured data organisation

The Workout Plan structure demonstrates how information from multiple parts of a database can be connected through relationships.

## Application Development

Genio was used to transform the underlying database structure into a functional application.

This involved creating and configuring:

- Data tables
- Forms
- Management pages
- Navigation menus
- Application layouts
- User dashboards

This provided experience working through multiple stages of application development rather than only designing the database.

## User Interface Design

The application was structured so that users could navigate between different management areas and interact with the information stored in the database.

Separate pages were created for clients, gyms, employees, instructors, workout plans, workout types and exercises.

The layout and visual theme of the application were also configured within Genio.

## Testing and Problem Solving

Developing the system required checking that database relationships, forms and interface components worked together correctly.

Testing different parts of the application provided practical experience identifying configuration issues and reviewing system behaviour during development.

## Teamwork

The Gym Management System was developed during an internship at Quidgest in Lisbon alongside another intern.

Working together on the project provided experience collaborating on the development of a shared system and contributing towards a completed application.

## Presentation

At the end of the project, the completed Gym Management System was presented to the team.

This provided experience demonstrating a technical project and explaining how the completed system worked.

## Skills Developed

Through the project, practical experience was gained in:

- Relational database design
- Primary and foreign keys
- Data modelling
- Application development
- Form development
- User interface configuration
- Testing
- Problem solving
- Teamwork
- Technical presentation
