# Testing and Troubleshooting

## Overview

Testing was carried out throughout the development of the Gym Management System to check that the database structure, forms and application interface worked together correctly.

The system was reviewed as new components were added so that relationships between tables, data entry forms and navigation could be checked before the project was completed.

## Database Testing

The database structure was checked to ensure that the required tables and fields were available within the system.

Primary keys were used to identify individual records, while foreign keys were used to create relationships between related tables.

Particular attention was given to the Workout Plan table because it connects information from several areas of the system, including clients, instructors and gyms.

## Form Testing

The forms were tested to ensure that they provided access to the correct fields from their associated database tables.

Forms were created and reviewed for:

- Clients
- Employees
- Exercises
- Gyms
- Instructors
- Workout Types
- Workout Plans

This helped confirm that information stored within the database could be accessed and managed through the application's interface.

## Navigation Testing

The application's menu structure was reviewed to ensure that users could navigate to the main areas of the Gym Management System.

The menu provided access to clients, gyms, employees, instructors, workout plans, workout types and exercises.

The Admin and Staff dashboards were also reviewed as part of the completed interface.

## Relationship Testing

Relationships between records were an important part of the system.

The Workout Plan functionality was used to confirm that information from different parts of the database could be connected within a single record.

This demonstrated that the relational database structure could support the intended functionality of the application.

## Troubleshooting

During development, the system was reviewed as tables, forms and interface components were configured in Genio.

When a component did not behave as expected, its configuration and relationship with other parts of the system could be checked before continuing development.

This iterative approach helped ensure that the individual components worked together as part of the completed Gym Management System.

## Result

The final system combined the database, forms, dashboards and navigation into a working application.

Testing the individual components throughout development helped confirm that information could be organised, accessed and connected across the system.
