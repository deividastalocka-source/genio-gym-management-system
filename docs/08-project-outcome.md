# Project Outcome

## Overview

The final outcome of the project was a functional Gym Management System developed using Genio during the Quidgest internship.

The system combined a relational database with forms, dashboards, navigation and management pages to provide a structured application for managing gym-related information.

## Completed System

The completed application provided functionality for managing:

- Clients
- Employees
- Gyms
- Instructors
- Exercises
- Workout types
- Workout plans

These areas were connected through the underlying database structure and made accessible through the application's interface.

## Database Implementation

A relational database was created to organise the information required by the system.

Primary and foreign keys were used to establish relationships between records. This was particularly important for workout plans, where information from different parts of the system could be brought together within a single record.

## Application Interface

The database was developed into a usable application through Genio.

The completed system included:

- Admin and Staff dashboards
- Management pages
- Data entry forms
- Application navigation
- User management
- Customised layout and theme

This provided a graphical interface for interacting with the information stored within the database.

## Project Delivery

The Gym Management System was developed alongside another intern during the Quidgest internship in Lisbon.

At the end of the project, the completed system was presented to the team. The presentation demonstrated the application and explained its main functionality and design.

## Outcome

The project provided practical experience taking an application from its database design through to a working interface.

It demonstrated how relational database concepts could be applied within a business application and provided experience with application development, testing, teamwork and presenting a completed technical project.
